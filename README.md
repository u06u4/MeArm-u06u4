摘要
本專題結合工程設計流程(EDP)，採用「專題式學習」（Project-Based Learning, PBL）模式，使用 Arduino Uno R3 開發板、小型伺服馬達、雙軸搖桿擴充模組等硬體材料，開發一台基於四連桿 MeArm 機構形式的四軸機械手臂。專題貫穿工程設計流程，從定義問題、研究規劃、設計實作、測試評估到反思優化等步驟，嘗試解決機械設計、電子控制與軟體程式編寫的整合性挑戰。最終成果不僅成功驗證了 MeArm 機構的簡潔高效與 Arduino 平台的控制能力，更重要的是，在協作中培養了團隊問題解決、創新設計與工程實踐的核心素養。
